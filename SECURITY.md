# Security

FDCAD makes no network connections of its own (the optional update check is off by default), runs no code from part files and sends no telemetry.

If you find a security problem, for example a part file that makes FDCAD run code or write outside the folders you chose, please do not open a public issue. Email FDCAD@proton.me with the FDCAD version (Help, About), your system and the steps or the file that shows it. You get an answer within two weeks.
