## 3. Corrections made

| ID | Found in | Problem | Cause | Fix | Test |
|---|---|---|---|---|---|
| C1 | SC-02, app sweep | Scale with Uniform scaling off always said "made invalid geometry" in the preview. | The preview scales the part as shown, which carries the display mesh; the per axis transform then failed its check. A fresh rebuild worked, so it only showed in the app. | Per axis scaling transforms a copy without the mesh. | `test_scale_per_axis_of_a_meshed_part` |
| C2 | LP-02, app sweep | Linear Pattern with Fill: Up to reference failed with "'count1' is missing". | The panel hides and leaves out the count for Up to reference, but the feature still required it. | The count is optional; Up to reference works out the count itself. | `test_fill_up_to_a_reference_needs_no_count` |
| C3 | MT-01, app sweep | Modeled Thread on a 6 mm shaft failed at once with "the thread profile is wider than the pitch", for every size but the right one, and the size started at M5. | The size never followed the picked edge, and the message named a side effect, not the cause. | A picked round edge now picks the size that fits it (a 6 mm shaft: M6; a 5 mm hole: M6 by its tap drill). When the size is still wrong, the message says the shaft (or hole) and thread sizes and to choose the matching size. Also for Cosmetic Thread. | `test_a_picked_round_edge_picks_the_size_that_fits`, `test_a_size_far_smaller_than_the_shaft_says_so` |
| C4 | Panel sweep | Error messages showed internal names, such as "'count1' is missing" and "'end_condition' must be one of blind, mid_plane...". | The shared value checks quoted the parameter key. | Messages use words: "the count 1 value is missing", "the chosen end condition does not work for this feature". Same in Scale, Move Face, Lip and Groove, Mounting Boss and Snap Hook. | `test_missing_values_are_named_in_words` |
| C5 | App sweep | Edge Flange, Hem and Miter Flange errors showed internal edge names, for example "edge edge(f7/side/e5\|f7/side/e8) is not a straight outside edge". | The message used the stored edge name. | They say "edge 2" (its place in the list), or "the picked edge" for Tab and Slot. | Sheet metal tests |
| C6 | Geometry pass | Print Estimate could be about 1% off for round bodies after a per axis Scale or a deformation (75398 mm3 read as 76048). | The quick volume calculation is coarse on B-spline faces. | Print Estimate uses the precise calculation (relative error 1e-6, under 0.1 s on every sample). | Printing tests |

## 4. Checked and not a bug

| Seen | Why it is correct |
|---|---|
| Draft took one of four picked side faces as the neutral face | A new Draft starts with Pick Neutral Face on, so the first flat face clicked is the neutral face, as the panel says ("Choose a neutral plane or click a flat face"). Picking the neutral face first gives the right result. |
| Delete Face: Delete always failed | The Delete choice is greyed out in the panel until open surfaces exist; the script chose it from code. |
| Deform tools said "Origin X: Enter a value" | Only when opened outside their command. From the ribbon the triad is placed on the part. |
| Plane: Parallel to screen not defined | It needs Use Current View, which a script without a screen cannot press. |
| Many "pick a direction", "pick a plane" messages | Correct prompts for options the script gave no picks for. |

## 6. Running it again

The scripts are in `tools/test_plan_run`. Run each from the repository root; each writes a JSON log to the path given.

    QT_QPA_PLATFORM=offscreen uv run python tools/test_plan_run/numeric.py numeric.json
    QT_QPA_PLATFORM=offscreen uv run python tools/test_plan_run/sweep_app.py app.json
    QT_QPA_PLATFORM=offscreen uv run python tools/test_plan_run/refs.py refs.json
    uv run python tools/test_plan_run/shots.py shots

`shots.py` needs a real screen (no offscreen platform). `sweep_app.py` takes command names to run only those, for example `scale linear_pattern`.
