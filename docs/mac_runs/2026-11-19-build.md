## What differed from the Windows run

1. Tests: 7073 passed on the Mac against 7069 on Windows. The Mac skips 122.
2. One of two full runs aborted after the last test, while Python shut down. All 7073 tests
   had passed and the summary was printed. Qt printed "QObject: shared QObject was deleted
   directly. The program is malformed and may crash.", then macOS stopped the process:
   "pointer being freed was not allocated", in `PySide::destructionVisitor`, called from
   `PySide::destroyQCoreApplication`, from PySide's own exit handler. It did not happen in
   the second full run, in `tests/ui` run alone, in six runs of 60 UI test files each, in
   each of the eight changed test files run alone, or in either full run on `mac-fixes` at
   `d66ed0f1`. So it is not tied to one test that could be found, and it is new or newly
   visible since `c085f2aa`. It is in the test process's shut down, not in a test. The cause
   is not known. The macOS CI job would report such a run as failed.
3. PyInstaller warned that it ignores `/usr/lib/libproc.dylib` imported in `sysinfo.py`
   (D2711), because it is named by its full path. That is as meant: it is a system library
   and is not put in the bundle.
4. `make_dmg.sh` printed that `hdiutil create -format` is deprecated in macOS 27 in favour of
   `diskutil image create`. It still works.
5. Budget times were not measured again on this commit; `docs/mac_runs/2026-11-19.md` has
   those for `d66ed0f1`. All 97 budget tests passed here.
