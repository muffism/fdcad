## Stage 1 order, with how to reproduce

1. **Naming picks the wrong face silently** (audit E item 13). Build a plate, cut a slot that splits the top face, put Move Face on the right hand piece, then move the slot or add a second slot: the Move Face moves another piece with no warning. Same pattern with a split line, a revolve profile that gains a segment (faces named by position), and Replace From File with a STEP file that has more faces (faces named by file index). Fix: when a name goes through a split suffix, a position fallback name or an imported face index, compare the found face with the stored snapshot (PLAN.md section 6 item 5); if it does not match, use the snapshot rule (one clear match gives a warning, otherwise a lost reference). Add each case as a naming test. Also: the top face of a mirrored boss reports a downward normal, so a sketch on it faces down.
2. **Unit change rescales the model** (audit D3 item 1). Part in mm, rectangle dimensioned "20" and "10", extrude depth "25" (bare numbers), switch the part to inches: the body becomes 25.4 times larger. Values with a unit ("25mm") are unaffected. PLAN.md section 7 item 1 says geometry never changes. Fix by keeping the unit each value was typed in, or by rewriting bare numbers with the old unit when the part unit changes; a file saved before the fix must open with the same geometry.
3. **Twisted sweep and kernel guards** (spec section 19, audit E items 1 and 2). A 2 by 4 profile swept along a straight 20 mm path with twist "angle" (even 0 degrees) gives a volume 0.16 percent too large, 5 percent wrong at 70 mm, and fails at 100 mm, all reported OK. Add an exact case test and a golden sample, and look for a twist method that is exact. Face merging after a boolean can raise an uncaught kernel error and throw away a valid result: catch it and keep the unmerged shape. Add a result sanity check after booleans and fillets. Consider a guarded worker for fillets (a native stack overflow cannot be caught in Python).
4. **Splines dropped from paths** (spec section 20 item 2, audit D2). A sweep path of a line plus a spline sweeps the line only; a spline only path fails with an index error (`core/features/sketch_paths.py`). Same family: offset chains, sketch fillet, trim and pattern picks that ignore splines and ellipses without a message, and a sketch with a crossing plus any spline failing as a whole.
5. **Paste into another part keeps old references** (audit D3 item 3). Copy a cut whose end is "up to face" in one part and paste it into another: it keeps the face name, which in the target belongs to an unrelated feature, and cuts the wrong depth. Drop or remap references when the target document differs, and say so.
6. **Damaged and hostile files** (audit D12 items 1 to 8). The 3MF reader's vertex and triangle patterns slow down sharply on malformed tags and the mesh is read on every rebuild; 3MF, embedded blocks and sketch pictures decompress with no size limit; deep JSON nesting, huge integers and very deep formulas raise errors that are not reported as a damaged file. Keep each sample small in tests.
7. **Quit and rebuild state** (audit D3 items 4 and 12, E item 12). Quit with two unsaved parts, Discard the first prompt, Cancel the second: the discarded part is already gone. A cancelled rebuild says "Rebuilt in N s" and Export then writes the partial body.
8. **Edge flanges in mirrors and patterns** (audit E item 7). Mirror an Edge Flange as a feature: refused, the message says to pick its faces; picking the faces is refused with a message that contradicts the first. Flatten then reports OK and flattens only the original.
9. **The rest**: spec section 20 and the audit's High and Medium items section by section, then docs fixes (user guide tab names, tutorials, SHORTCUTS.md Ctrl+Shift+S and unbound default keys, FDEF_SPEC.md and PHASE5_SPEC.md where the audit found the document wrong; SHORTCUTS.md and FDEF_SPEC.md are owner files, so list the changes in the pull request), the robustness tests in spec section 21, and the Low items.
