# FDCAD User Guide

FDCAD is a desktop part modeller. You draw sketches, turn them into solid features, and change any value later. The part rebuilds from its feature tree every time, so an edit near the top flows through everything below it.

This guide is for new users. Start with Getting Started, then follow the tutorials. Use the tool pages when you need the details of one command.

## Start here

1. [Getting started](getting-started.md): the window, the feature tree, the property panel, files, undo and errors.
2. [View and selection](view-and-selection.md): turning and zooming the view, display styles, hiding items and picking faces, edges and points.
3. [Typing values](typing-values.md): units, fractions, arithmetic and formulas in any value field.
4. [Tutorials](tutorials/README.md): step by step parts, built on the sample parts that come with FDCAD.

## Keys

Every command can have a key. The default keys are listed on each tool page, and you can change them in Preferences. FDCAD uses Ctrl on Windows and Cmd on a Mac.
