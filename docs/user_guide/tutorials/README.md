# Tutorials

Each tutorial builds one of the sample parts from a New Part, step by step, with the same names and sizes as the sample. At the end you compare your part with the sample file. Open the samples with File, Open and the samples folder, or with File, Open Sample. The node editor samples are in the samples/graphs folder; open them with File, Open.

Start with [../getting-started.md](../getting-started.md) if you have not used FDCAD before. Then work through the tutorials in this order:

1. [plate-with-holes.md](plate-with-holes.md): sketch, extrude and cut a plate driven by global variables.
2. [bracket.md](bracket.md): an L profile extruded with Mid Plane, with holes sketched on its faces.
3. [turned-shaft.md](turned-shaft.md): a stepped shaft made with Revolved Boss and a groove with Revolved Cut.
4. [enclosure.md](enclosure.md): a box with fillets, shelled to 2 mm walls.
5. [lofted-handle.md](lofted-handle.md): a grip lofted from a rectangle to a circle.
6. [swept-spring.md](swept-spring.md): a helix and a round wire swept along it.
7. [piped-frame.md](piped-frame.md): a hollow tube along a rectangular path.
8. [split-with-pins.md](split-with-pins.md): a block too long for the printer, split in two with alignment pins.
9. [sheet-metal-bracket.md](sheet-metal-bracket.md): a base flange, an edge flange and its flat pattern.
10. [configured-bolt-family.md](configured-bolt-family.md): three bolt sizes from one design table.
11. [twisted-bar.md](twisted-bar.md): a square bar twisted a quarter turn with a deform feature.
12. [attractor-plate.md](attractor-plate.md): a hole pattern built in the node editor.
13. [fit-test-plate.md](fit-test-plate.md): pins and holes with stepped gaps, to find your printer's fit.
14. [living-hinge-strip.md](living-hinge-strip.md): a strip that bends where it has slits.
15. [storage-bin.md](storage-bin.md): a bin on a 42 mm grid, every size from a variable.
16. [nut-and-bolt.md](nut-and-bolt.md): an M8 nut and bolt with modelled threads.
17. [print-in-place-hinge.md](print-in-place-hinge.md): a hinge that prints as one piece and turns.
18. [bin-base-grid.md](bin-base-grid.md): the grid plate the storage bins sit on.
19. [hex-fasteners.md](hex-fasteners.md): an M6 bolt, nut and washer sized from the screw tables.

Every tutorial ends with a "Try this" section. Make the change, watch the part rebuild, and use Undo (Ctrl+Z) to go back.
